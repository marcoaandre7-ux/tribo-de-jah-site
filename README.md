# Tribo de Jah — protótipo do site

Protótipo estático em HTML, CSS e JavaScript. A abertura usa o vídeo de demonstração e uma fotografia provisória. Agenda, história, contatos e capas serão substituídos por conteúdo oficial.

## Visualizar localmente

Sirva a pasta `dist` com um servidor HTTP local, por exemplo:

```sh
python -m http.server 4173 --directory dist
```

Abra `http://localhost:4173` no navegador.

## Publicação

O `vercel.json` configura a pasta `dist` como saída do site na Vercel. Não há etapa de compilação nem banco de dados neste protótipo.
